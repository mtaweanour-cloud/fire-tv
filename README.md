# Fire TV AirPlay Receiver

Free, ad-free AirPlay screen mirroring receiver for Amazon Fire TV.

## Install on the Fire TV
1. Fire TV: Settings → My Fire TV → Developer options → Install unknown apps → turn on for **Downloader**.
2. Open Downloader and enter:
   `https://github.com/mtaweanour-cloud/fire-tv/releases/latest/download/FireTV-AirPlay.apk`
3. Install, then open **AirPlay Receiver**.

## Use
On iPhone/iPad: Control Center → Screen Mirroring → pick the Fire TV.

The app updates itself: each time it opens it checks for a newer build.
Press ☰ on the remote for the diagnostics log, or open `http://<tv-ip>:7777` on a phone on the same Wi-Fi.

Built automatically by GitHub Actions on every push to `main`.
